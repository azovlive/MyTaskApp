# Google Tasks Custom App (Chrome Extension)

이 프로젝트는 구글 태스크(Google Tasks) API를 활용하여 제작된 개인 맞춤형 크롬 확장 프로그램입니다. MS To-Do 스타일의 직관적인 UI를 제공하며, 효율적인 작업 관리를 위해 설계되었습니다.

## 📝 프로젝트 목적
- **효율적인 할 일 관리:** 구글 태스크의 데이터를 기반으로 미완료 작업과 완료 작업을 명확히 분리하여 생산성을 높입니다.
- **커스텀 편의 기능:** 드래그 앤 드롭을 통한 작업 순서 변경, 목록 간 이동, 마감일 관리 등을 통해 구글 공식 앱보다 빠른 인터페이스를 지향합니다.
- **스마트 리스트:** '오늘 할 일' 기능을 통해 마감 기한이 지난 작업과 오늘 마감인 작업을 자동으로 필터링합니다.

## 🛠 주요 환경 및 기술 스택
- **기반:** Chrome Extension Manifest V3
- **언어:** JavaScript (ES6+), HTML5, CSS3
- **API:** Google Tasks API
- **인증:** Google OAuth 2.0 (Identity API)
- **개발 환경:** Chrome Browser (최신 버전 권장)

## 🚀 주요 기능
- **직관적인 UI/UX:** 미완료/완료 작업의 자동 분리 및 가독성을 높인 레이아웃.
- **드래그 앤 드롭:** 마우스로 자유롭게 작업을 순서 변경하거나 다른 목록으로 이동 가능.
- **마감일 관리:** 날짜 선택기를 통한 마감일 설정 및 요일 자동 표시.
- **스마트 리스트:** '오늘 할 일' 탭을 통해 즉시 처리해야 할 업무 집중 관리.
- **효과음 및 딜레이:** 작업 완료 시 피드백 사운드와 시각적 전환 딜레이 적용.

## 📥 설치 방법
1. 이 저장소를 다운로드하거나 `git clone` 합니다.
2. 크롬 브라우저에서 `chrome://extensions/`로 이동합니다.
3. 우측 상단의 **'개발자 모드'**를 활성화합니다.
4. **'압축해제된 확장 프로그램을 로드합니다'** 버튼을 클릭합니다.
5. 프로젝트 폴더(`MyTaskApp`)를 선택하면 설치가 완료됩니다.

## ⚠️ 필수 주의사항
- **API 설정:** 사용 전 [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 생성하고, `Tasks API`를 활성화한 뒤 `Client ID`를 발급받아 `manifest.json`에 등록해야 합니다.
- **보안:** 깃허브에 코드를 올릴 때는 `client_id`와 같은 민감한 정보를 반드시 제거(또는 환경변수 처리)한 후 업로드하십시오.
- **API 사용량:** 무분별한 API 호출을 방지하기 위해 데이터를 호출할 때 페이지네이션(`maxResults=100`)을 적용하였으며, 과도한 테스트는 할당량 제한을 초래할 수 있으니 주의 바랍니다.
- **라이선스:** 이 프로젝트는 개인 학습 및 생산성 향상을 위한 목적으로 제작되었습니다.
